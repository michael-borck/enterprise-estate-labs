# Schedule Mapping

This repo is unit-agnostic. Modules are numbered by topic. Map them onto a teaching
calendar by editing the right-hand columns of this one file. Nothing else in the repo
references week numbers or dates.

The mapping below is for ISYS2008 Enterprise Technologies, Semester 1, 2027. Teaching
weeks follow the 2026 calendar shape (Weeks 1-7, tuition-free Weeks 8-9, teaching Weeks
10-14). Confirm against the 2027 calendar before release.

| Lab module | Topic | ISYS2008 module | Teaching week | Notes |
|---|---|---|---|---|
| 00 | Environment setup | 01 | 1 | Install Docker or Podman, pull images, run the smoke test |
| 03 | Processes, memory and containers | 03 | 3 | First running estate; resource limits |
| 04 | Networking models | 04 | 4 | Host-side capture and network inspection (uses `m03`) |
| 05 | Addressing and naming | 05 | 5 | Planned |
| 06 | Protocols and the web tier | 06 | 6 | Reverse proxy, TLS, certificate fault |
| 08 | Identity and access | 08 | 10 | Planned |
| 09 | File systems and access control | 09 | 11 | Shared volume, ownership, permission fault |
| 10 | Storage, virtualisation and cloud | 10 | 12 | Planned |
| 11 | Security, privacy and incident response | 11 | 13 | Planned |

The unit's `COVERAGE_MATRIX.md` is the authoritative mapping for assessment. This file
is the lab runner's view of the same calendar.
