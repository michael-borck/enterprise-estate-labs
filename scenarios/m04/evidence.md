# Evidence: Module 04

Record these in your portfolio or conversation log.

| Item | What to capture |
|---|---|
| Interface | `ip -brief addr` in the tools container |
| Route | `ip route`; the default gateway |
| Name | `getent hosts web`; the address it returns |
| Capture | The handshake, the request and the response |
| Refusal | The reset on port 81 and the curl error |
| Judgement | A check with an owner and an alert |

## Challenge prompt

Ask an AI assistant to explain a frame, a packet and a segment. Then ask which layer a switch
uses and which layer a router uses. Check the answer against the capture. Record what it got
wrong or left out.
