# Evidence: Module 06

Record these in your portfolio or conversation log.

| Item | What to capture |
|---|---|
| Certificate | Subject, issuer, expiry and why the browser does not trust it |
| Path | Browser to proxy to web, and where TLS ends |
| Proof | The proxy and web log lines for one request |
| Break | What you changed, the status code, and the log that showed it |
| Judgement | Trust the internal CA, buy a public certificate, or change the design |

## Challenge prompt

Ask an AI assistant to explain the warning. Then ask it what it would tell a customer
support agent in one paragraph. Check whether the explanation distinguishes
authentication from encryption. Record what it got wrong or left out.
