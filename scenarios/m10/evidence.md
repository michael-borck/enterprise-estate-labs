# Evidence prompts

Capture the following for your portfolio:

- The backup log line that says the backup completed.
- The size of the backup file and the number of data statements in it.
- The restore output: rows in the live database versus rows in the restored database.
- The backup command before and after the fix.
- A new restore after the fix, with matching row counts.
- The recovery point objective (RPO) and recovery time objective (RTO) you would set for
  this database, and why.
- Your recommendation for backup storage: local volume, offsite object storage or a managed
  database backup. Include cost, risk, restore time and who owns the restore test.
- One place where AI was wrong, vague or over-confident about backup or restore.
